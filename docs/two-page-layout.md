# 校史照片与双时间轴

更新日期：2026-10-21。开发分支：`codex/new-page`。

## 本次改动

- 后续批注：取消全部照片总览及右上角文字／小房子按钮，双时间轴也不再提供全部主题入口。默认和三分钟自动返回均显示校园发展；详情中的关闭按钮及缩放等交互保留。

- 默认页面为“校史照片”，预先选中“校园发展”。照片按年份沿平面折返线排列，首行从左向右、次行从右向左，依次向下；单图独立展示，双图错位堆叠，多图采用紧凑交叠堆叠。
- 按用户选定的 B 方案，主题内所有事件在一屏内完整展示，按事件数及窗口尺寸调整行列、间距和照片尺寸，不增加分页或相册滚动。拖动、滚轮不会移动或拉近整个照片集，也不会切换页面。
- 页面按钮改为“校史照片／双时间轴”，同步提供繁体和英文名称。通过这两个按钮主动切换页面，拖动照片集不会切页。
- 从原页面移出的树仁校史、香港教育史两条时间线及其文字面框放在“双时间轴”页面。上方标为“01 | 树仁校史”，下方标为“02 | 香港教育史”。
- 按后续批注调整：双轨作为整体在可用内容区水平、垂直居中；校史标题及面框在上轨上方，教育史标题及面框在下轨下方，每个面框都位于对应标题右侧。两轨中间保留滑动区域，五个主题按钮只在“校史照片”页显示。
- 两条时间线共享水平进度，保留原有事件点和年份；同一年份在两条线上使用相同的横坐标。中间空白区域支持左右滑动、鼠标拖动和滚轮，点击年份更新对应文字；两端不循环。
- 保留现有主题过滤和三种语言。照片详情打开时增加 1.65 秒的缓慢展开，同组照片略微错开启动时间；减少动态模式立即展开。详情归位、年份箭头、单张图片缩放和拖动、三分钟返回保持原有实现。
- 操作指引的三种语言已更新为两页说明，首次显示、手动打开及三分钟无操作后重新显示保持不变。
- 没有修改 Excel、正式 JSON 或照片文件，也没有提交、推送或部署。

## 实现位置

- `src/app/App.tsx`：页面切换与共用主题、语言、指引及详情状态。
- `src/timeline/TimelineScene.tsx`：照片页面、折返连线与各照片组的年份标签，复用原详情控制器。
- `src/timeline/flatAlbum.ts`：主题照片分组、时间排序、单屏自适应折返布局及展开错峰进度。
- `src/styles/flat-album.css`：平面照片外观及年份。
- `src/timeline/DualTimelineScene.tsx`：双时间轴及两个文字面框。
- `src/timeline/HorizontalTimelineController.ts`：两条时间轴的共享横向滑动、年份点击、键盘与边界处理。
- `src/timeline/horizontalTimeline.ts`：沿用原早年时间间距，保证不同年份标记之间有可读间隔。
- `src/components/TapButton.tsx`：处理触屏滑动之后可能缺失的兼容性 click，保留鼠标及键盘点击，并防止拖动被当成轻触。
- 时间轴容器使用 `overflow: clip`，防止浏览器聚焦年份时对上／下轨分别产生隐藏滚动，从而破坏同一年份的横向对齐。
