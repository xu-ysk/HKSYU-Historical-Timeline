## 完整回归中的采样修复

完整检查发现两个旧动画测试存在启动顺序问题：滚轮输入返回后才开始观察移动帧，可能接近动画结束；主题测试未等待采样器启动就点击，可能漏掉开头的缩放帧。

修改测试的采样启动顺序为“先确认观察器已启动，再输入滚轮或点击主题”。保留原来的所有验收断言，包括待完成位移大于 0.01、缩放中间帧数大于 5、帧间变化小于 0.2、位置精确恢复、照片数量和主题选择等。三种浏览器分别连续运行相关两项测试三轮，共 18/18 通过，再重新运行完整检查。没有删除、跳过测试、降低阈值或启用自动重试。
