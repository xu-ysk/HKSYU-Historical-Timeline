## ③ 点击任意位置返回时间轴

- 删除可见的“返回时间轴”按钮，消除其与“全览／浏览”的重叠。
- 详情期间通过覆盖页面的透明交互层接收点击：照片、文字、空白、语言、主题及视图切换区域均可返回。

验证：新增 2 项详情组件测试，覆盖点击只触发一次关闭、移除旧按钮、辅助描述、Tab／Escape 与监听清理；新增 `detail-dismiss.spec.ts`，真实点击六类页面区域并确认精确归位、不误触底层控件，覆盖双照片展开途中关闭与重复点击。该项及原有照片、动画、长文字、跨年和减少动画回归共 21 项 Chromium 测试通过。

## 验收步骤

1. 查看页面顶部：英文馆藏标题已移除，繁／简／英入口及主副标题保留。
2. 查看右下角五个主题框：只有名称与颜色，没有 A～E 或“全部主题”；逐个点击主题，再点同一主题，确认恢复原样。
3. 点击一张照片打开详情，分别点击照片、文字、空白区域或控件所在位置，确认都能回到原位置。返回点击不应额外改变语言、主题或视图。
4. 打开双照片或展开途中点击返回；使用滚轮阅读长文字，再按 Esc 返回，确认原有浏览流程正常。

此版继续使用本地占位内容，不接入真实 Excel、学校照片或展厅触控功能。历史交互验证见 `interaction-validation.md`，本轮界面操作以本文为准。
