# T1 / T2 / T3 交互调整验证记录

日期：2026-09-29。适用版本：使用本地占位数据的电脑浏览器第一版。

本轮按①浏览、②主题、③抽出三个问题依次修改，每个问题增加对应测试并通过后再继续。参考 GIF 仅用于判断运动、排列和层次；未把其中的照片、文字或品牌内容引入网页。

## ① T1：整齐、循序的照片浏览

- 照片使用同一条连续路径，经过中央间隔时保持相同倾角，不再分别追赶不同动画目标。
- 同年不同事件拥有稳定的先后位置，可以逐一经过中央；同一事件的两张照片仍作为一组。
- 滚轮增量连续累计，并在停下后落到最近的事件位置。时间范围仍为 1949 年到当前年份，双时间线同步。
- 焦点和前后层次根据当帧实际位置计算，避免后面的照片抢到前面。

新增 `tests/unit/albumTrack.test.ts`、`tests/e2e/reference-browse.spec.ts`。覆盖同年与末年可达性、整段运动不逆行、不打乱顺序、保持平行、真实滚轮正反向逐一浏览；原有滚动边界、拖拽取消和教育史不遮挡检查继续保留。

## ② T2：主题缩放与遮挡

- 全览改为参考中的较窄封套队列；浏览照片保持 238px 的基础宽度。
- 选中主题维持正常比例 1，其他主题平滑缩到 0.35，并处于较低层次，避免缩小照片盖住选中照片。
- 双照片轻微错开，两个入口都保留可点击区域；切换主题不改变事件顺序、年份或节点数量。

新增 `tests/unit/themeLayout.test.ts`、`tests/e2e/reference-themes.spec.ts`。逐一检查 A～E 在全览、浏览中的比例、层次及每张可见选中照片的实际鼠标命中区域，并验证连续快速切换的中间缩放值。保留原有主题比例和语言切换测试。

## ③ T3：连续抽出与归位

- 从被点击照片当时真正绘制的位置开始，先抬离队列，再逐渐转正和放大。
- 其余照片向两侧退开，说明文字在照片接近展开后渐显；保留原有左图右文、完整比例和长文字滚动。
- 同事件双照片同步抽出；空白照片使用相同路径。关闭时从当前姿态连续归位，也支持在展开途中按 Esc。
- 打开照片会冻结当前滚动位置，并清除尚未到达的旧滚轮目标；返回后从冻结位置继续操作。
- 减少动画偏好下仍能完成所有操作，新增阴影过渡也会关闭。

新增 `tests/unit/extraction.test.ts`、`tests/e2e/reference-extraction.spec.ts`。覆盖左右非中央照片的真实鼠标点击、双照片、空白照片、抬起后放大、延后文字、逐帧连续性、原 DOM 与精确归位、中途返回、展开中切主题，以及滚动未结束时打开和返回继续滚动。

## 测试修复说明

- 旧详情测试在“最近事件”刚改变时记录返回位置，而此时移动尚未完成。改为等待导航到达目标，再记录位置；初始年份尚无导航目标时按当前位置判断。原有精确焦点、主题、语言和节点断言均保留。
- 新增抽出测试最初让异步定位与鼠标点击同时启动，完整回归中出现漏掉开头采样的情况。改为确认帧记录器已就绪后点击，记录到展开结束，并将逐帧数据附在 Playwright 报告中。仍要求超过 15 个中间帧、超过 10 个不同尺寸、每帧运动距离与速度受限、延后文字及精确归位。
- 完整回归还发现 Edge 的 1920px 全览在覆盖共用 PNG 时发生 Windows 文件写入错误，页面布局断言已通过。所有自动截图改用 Playwright 各测试、各浏览器独立的输出路径，不再覆盖历史验证图片；截图调用与断言全部保留。本轮人工检查过的图片单独保存为 `screenshots/interaction-*.png`。
- 不删除测试，不设跳过或自动重试，不下调帧数、连续性和性能标准。

## 人工验收顺序

1. 在全览中滚动进入浏览，连续向前、向后滚动，并尝试拖动，观察照片是否依序穿过中央间隔。
2. 在全览和浏览中分别切换 A～E，观察选中主题保持正常大小、其他主题缩小，随后点击“全部主题”恢复。
3. 点击中央和两侧任意可见照片，观察抬起、转正、放大及文字出现的顺序；按 Esc 或“返回时间轴”关闭。
4. 尝试双照片和空白照片，展开途中关闭，并在详情中切换主题或语言后返回。

抽出过程的中间帧见 `screenshots/interaction-extraction-frames.png`，主题缩放画面见 `screenshots/interaction-theme-overview.png` 和 `screenshots/interaction-theme-browse.png`。图中英文字母和说明均为示例；真实 Excel、学校照片和展厅触控仍属于第二版范围。动画相似度和观感等待用户在网页验收。
