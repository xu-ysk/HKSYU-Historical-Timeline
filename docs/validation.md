## 階段 6：問題定位與修復

- 香港跨年檢查加入午夜計時器和 visibilitychange，更新資料時保留當前年份焦點、主題與選中事件。
- 減少動畫偏好下，零時長歸位會先於 React 恢復按鈕可用狀態；改為下一動畫幀恢復焦點，原焦點斷言通過。
- 跨年瀏覽器測試最初固定 Date.now，凍結了 GSAP 的時間來源；改為持續前進的 Playwright clock，仍驗證打開頁面實際跨年。
- 性能初次 P95 約 50～50.1 毫秒，未達原定小於 50 毫秒標準。減少重複尺寸寫入、為可見卡片配置合成層、緩存 React 卡片、移除不必要陰影，並將性能採樣與每操作 DOM 快照錄製分開；相同 30 秒操作、幀數和 P95 斷言復測通過。
- 新增逐幀檢查抽取照片經過多個中間位置，確認不是瞬間替換；鼠標實際點擊雙照片兩個入口，確認同事件一起抽出。
- 雙照片入口最初暴露邊緣過窄且測試在移動中取點；照片改為輕微展開，測試等待實際幾何位置穩定並選取有周邊餘量的命中點。所有原斷言保留。
- Edge 報告站點圖標 404；新增本地 SVG favicon 後，三套瀏覽器的動畫及啟動測試共 9 項全部通過，未忽略控制台錯誤。
- 依賴已由 `npm ci` 從鎖文件重新安裝，npm audit 為 0；所有測試未設 skip、未刪除失敗測試、未使用自動重試。
- 最終全覽截圖發現首年照片被左下導航背景遮擋一角；縮小全覽軸的可用高度、保留照片尺寸，新增首張照片完整避開導航區的三尺寸斷言。

## 實施範圍與限制

- 此版是可互動的前端框架，歷史內容、照片及譯文均未接入 Excel；事件英文字母及說明屬示例。
- 真實照片訪問權、Excel 線上位置、職員更新後的刷新／緩存策略和觸控大屏驗收留待第二版。
- 已完成桌面瀏覽器鼠標／鍵盤的自動化操作及截圖視覺檢查；未聲稱由最終用戶完成實體硬件操作驗收。
- 性能採樣使用空白占位卡片，不能代表第二版真實高清照片的載入、解碼和網絡性能。

## V2 真實資料與展覽觸屏驗證（2026-10-05）

第二版已改由 `public/timeline.json` 和 `public/Historical_Timeline_Images/` 提供正式本地資料，避免依賴只能由校內電腦訪問的照片伺服器。`npm run import:data` 讀取工作簿與照片鏡像，輸出 28 條上軌事件、118 條樹仁校史事件、20 條香港教育史事件及 185 張照片；重新匯出的 JSON 與目前快照一致，185 個照片路徑均能解析到本地文件。

第二版加入粗指標觸屏命中區和觸控輕點開啟照片的處理。`npm run check` 最終結果為 198/198 瀏覽器測試通過，包含 Chromium、Chrome、Edge 各自的展覽觸屏測試；`npm run build` 之後的正式 `dist` 包含真实 `timeline.json` 和全部本地照片。預覽中 `timeline.json` 與含中文目錄的照片请求均返回 HTTP 200。

展示目標是約 85 寸橫向展覽觸屏。当前自动化触屏测试使用 1920×1080 视口模拟粗指标输入；实体屏幕的像素分辨率、系统缩放、浏览器和触控驱动仍待场地确认。手機和平板不在第二版適配範圍內。

本轮曾发现 Chrome/Chromium 主题快速重定向测试在高负载下采样帧数不足；保留严格的“超过 5 个中间缩放帧”断言，并让测试序列在同一首张卡片上重复放大和缩小后复测通过。没有删除、跳过或降低任何断言。

三条上轨测试在 1280×720、1440×900、1920×1080 全部通过；三图和四图详情测试均通过并保存截图。最终生产预览已用 `npm run preview` 启动，并通过 `Invoke-WebRequest http://127.0.0.1:4173/` 验证 HTTP 200（响应 587 字节）。
